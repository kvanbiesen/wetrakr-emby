WeTrakr settings are per user, so each user connects their own WeTrakr account. Users open them from their profile menu (click the user icon, then WeTrakr). As an admin you can open and edit any user's settings from the list below. You never see anyone's WeTrakr password: they sign in on wetrakr.com with a short code.
